# EVIDENCE-001 — Evidence Classification

| Code | Meaning |
|---|---|
| V | Independently verified against authoritative evidence |
| M | Directly measured |
| Q | Quoted by a supplier or service provider |
| C | Calculated from stated inputs and formulas |
| E | Engineering estimate |
| A | Assumption awaiting confirmation |
| H | Historical account or legacy record |
| U | Unknown or unresolved |

Evidence labels do not replace citations, test records, or source documents.
